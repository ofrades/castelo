# Using Vite+, the Unified Toolchain for the Web

This project follows the Bursa stack: TanStack Start, React, Tailwind, Nitro, SQLite, and Drizzle. Use Vite+ commands through `vp`.

## Common commands

```bash
vp install
vp dev
vp build
vp check
vp test
```

## Rules

- Use `vp install` instead of package-manager-specific install commands.
- Use `vp build`, `vp check`, and `vp test` to validate changes.
- Prefer small, direct changes. Keep reader and annotation ownership in native React TSX.
